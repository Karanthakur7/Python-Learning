# Python Learning

Welcome to my **Python Learning** repository! This repository documents my journey of learning Python from the fundamentals to intermediate problem-solving and programming concepts. It contains topic-wise practice scripts, hands-on exercises, and logic-building solutions written as a Computer Science & Engineering (B.Tech CSE) student.

---

## 📌 What I'm Learning

This repository covers core Python concepts and programming paradigms through hands-on code examples:

- **Variables & Data Types**: Understanding data types (integers, floats, strings, booleans), type casting, identifiers, and naming rules.
- **Input & Operators**: Taking user input and implementing arithmetic, relational, logical, and assignment operators.
- **Strings & Conditionals**: String indexing, slicing, built-in string methods, and decision-making structures (`if`, `elif`, `else`).
- **Lists & Tuples**: List operations, indexing, slicing, built-in list methods (`append`, `sort`, `reverse`, `insert`, `remove`, `pop`), and immutability of tuples.
- **Dictionaries & Sets**: Managing key-value pairs, nested dictionaries, dictionary methods (`keys`, `values`, `items`, `get`, `update`), set operations, and unique element manipulation (`union`, `intersection`).
- **Loops & Control Flow**: Iteration using `for` and `while` loops, sequence generation with `range()`, and loop control with `break`, `continue`, and `pass`.
- **Functions**: Writing modular, reusable code blocks, defining parameters and default arguments, and handling return values.
- **Recursion**: Solving problems recursively by defining base cases and recursive steps (e.g., sum of natural numbers, printing sequences).
- **File Handling**: Reading, writing, appending, and creating files using `open()` and `with` statements, alongside file management using Python's built-in `os` module.
- **Logic Building & Challenges**: Algorithmic problem-solving, palindrome checks, sequence generation, data verification, and search logic.

## 🚀 How to Use This Repository

### Prerequisites
Make sure you have **Python 3.x** installed on your system. You can verify your installation by running:
```bash
python --version
```

### 1. Clone the Repository
```bash
git clone https://github.com/YOUR_USERNAME/Python-Learning.git
cd Python-Learning
```

### 2. Run Any Script
Navigate into any topic folder and run the Python script using:
```bash
python "Loops_python/Forloops.py"
```
*(Or open the repository in your preferred IDE, such as Visual Studio Code, and run the files directly).*
